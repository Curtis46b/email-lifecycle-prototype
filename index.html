From volume to relevance

Redesigning email from a time-based drip into a behavior-driven lifecycle system.

The current system sends too much, too early, with unclear intent. The future system should send fewer messages, tied to user behavior, with distinct journeys for demand-side and supply-side members.

Executive Summary

The email program needs an operating model reset.

29+ Email steps in the current welcome loop
2x Emails per day during the first five days
4 Future lifecycle programs organized by intent

The redesign should move the company away from blasting a sequence and toward guiding different users through the moments that matter: trust, profile quality, engagement, and conversion.

Current State Problems

What is broken today

Key Insights

What actually drives performance

Timing beats volume.

Messages perform best when they arrive at high-intent moments.

Early trust matters.

The first few touches shape whether users believe the platform is worth engaging with.

User progress drives monetization.

Profile completion, messages, and matches create the conditions for conversion.

Premium brands send with restraint.

Lower frequency and higher relevance protect brand equity.

Behavior reveals intent.

The system should respond to what users do, not what day they are on.

Proposed Lifecycle Architecture

Four programs, each with a clear job

01

Welcome / Trust

Introduce the brand, explain the value, establish credibility.

02

Onboarding / Profile

Drive profile completion and quality through milestone-based prompts.

03

Engagement / Activity

Respond to messages, matches, favorites, and inactivity signals.

04

Conversion / Monetization

Serve upgrade prompts when the user has demonstrated intent.

System rules

Behavior over time • One job per message • Suppress redundant touches • Measure user outcomes

GM Journey

Demand-side journey: convert through value

1

Trust

Welcome, safety, platform differentiation.

2

Activation

Complete profile, receive signals, understand success.

3

Engagement

Messages, favorites, views, reply motivation.

4

Conversion

Upgrade when value is visible and friction is meaningful.

Principle: Sell outcomes, not access.

AF Journey

Supply-side journey: build quality and trust

1

Trust first

Safety, legitimacy, control, platform standards.

2

Profile quality

Help members build profiles that attract the right attention.

3

Engagement

Encourage thoughtful responses and return behavior.

4

Retention

Keep high-quality supply active and confident.

Principle: AF success drives GM conversion indirectly.

Current State

  • One long time-based welcome loop
  • High early cadence and daily sends
  • Mixed intent and multiple CTAs
  • GM and AF treated too similarly
  • Success measured mainly by opens and clicks
Measurement Plan

Measure whether users do the thing

Onboarding

Profile completion rate, time to completion, verification completion.

Engagement

First message sent, reply rate, matches, return rate.

Conversion

Upgrade rate, time to conversion, revenue per user.

System Health

Unsubscribes, spam complaints, volume per user, suppression impact.

Week 1–2 Test Plan

Start with the highest-signal changes

Test 1

Reduce early cadence

Move from 2 emails/day to 1 email/day in the first week.

Test 2

Move AF safety earlier

Shift trust and safety from late sequence to Step 2 or 3.

Test 3

Behavior-trigger profile prompts

Only send profile emails when the relevant step is incomplete.

Test 4

Remove AF upgrade messaging

Eliminate direct conversion asks from the AF welcome journey.
